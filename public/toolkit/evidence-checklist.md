# Evidence checklist: what an auditor or regulator may ask for

A list of the documents and records that each framework expects you to be able to show. Use it to prepare for an audit, a regulator's request or a customer's due-diligence questionnaire. Tick what you have, and note where it is kept.

Every item names the clause it comes from. Keep only the sections that apply to you.
